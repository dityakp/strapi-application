## 🚀 Setup Steps

### 1. Clone Repository

```bash
git clone https://github.com/strapi/strapi.git
cd strapi
```

### 2. Install Dependencies

```bash
yarn install
```

### 3. Build Project

```bash
yarn setup
```

### 4. Run Development Server

```bash
npm run develop
```

Access admin panel at: `http://localhost:1337/admin`
